# Taller Práctico Aprendizaje automático supervisado: Regresión y clasificación parte1

Este taller práctico permite aplicar y profundizar los fundamentos de aprendizaje automático supervisado estudiados durante la primera mitad del curso mediante un caso empresarial de solicitudes de servicio. A partir de datos históricos, los participantes analizarán relaciones entre variables operativas y construirán modelos de regresión para estimar tiempos de atención y costos asociados a nuevas solicitudes.

Durante la práctica, los participantes trabajarán con regresión lineal simple y multivariable, función de costo, descenso del gradiente, tasa de aprendizaje, vectorización, escalamiento e ingeniería de características. Mediante un notebook previamente estructurado, ejecutarán experimentos, modificarán parámetros definidos, compararán diferentes variantes del modelo e interpretarán métricas, coeficientes, predicciones y visualizaciones. El foco estará en comprender cómo las decisiones tomadas durante el modelado afectan los resultados y cómo utilizar las predicciones como apoyo para un caso de uso empresarial.
